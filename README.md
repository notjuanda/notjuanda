## En qué trabajo

- **Mencargo (Overscope):** plataforma de gestión de comunidades residenciales usada por unas 30 comunidades y más de 2000 miembros, en español, inglés y árabe. Módulos web y apps móviles con NestJS, Angular, Ionic y PostgreSQL.
- **Kiwi Finance** ([kiwifinance.lat](https://kiwifinance.lat)): plataforma multinegocio para restaurantes y comercios con punto de venta, inventario con recetas y costeo, pedidos por QR, reservas y un CMS propio para que cada negocio publique su web. Supabase y Vercel.
- **50+ Wellness Center:** sistema de membresías y clientes para unos 300 socios activos, con un chatbot conectado a WhatsApp.

## Proyecto público destacado

**[wordpress-mcp](https://github.com/notjuanda/wordpress-mcp)** — servidor MCP en TypeScript para administrar un WordPress self-hosted desde Claude (48 herramientas, REST + SSH/WP-CLI) con protecciones de seguridad: modo solo lectura, copias automáticas, reversión si un cambio PHP falla y confirmación para acciones destructivas.
